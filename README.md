# শিশুদের পরিপূরক খাদ্য ও সুস্থ থাকার গাইড

৬–২৩ মাস ও ছোট বাচ্চাদের জন্য পুষ্টিকর রেসিপি, বয়স অনুযায়ী দৈনিক চার্ট,
ট্র্যাকিং সিস্টেম, বিকাশের মাইলস্টোন চেকলিস্ট, খাবারের রিমাইন্ডার
এবং WHO/UNICEF/NHS নির্দেশিকা অবলম্বনে তৈরি একটি সম্পূর্ণ PWA।

## ফিচার

- **৬টি বয়স-ভিত্তিক দৈনিক খাবারের চার্ট** — ৬ মাস থেকে ২ বছর
- **১৮টি পুষ্টিকর রেসিপি** — উপকরণ, পুষ্টিগুণ, রান্নার ধাপসহ
- **দৈনিক ট্র্যাকিং** — ১ ক্লিকে OK, প্রোগ্রেস রিং, PNG কার্ড ডাউনলোড ও শেয়ার
- **বিকাশের মাইলস্টোন চেকলিস্ট** — ৫টি বয়স গ্রুপে ২৫টি ধাপ
- **খাবারের রিমাইন্ডার** — Notification API দিয়ে সময়মতো নোটিফিকেশন
- **ডার্ক মোড** — সিস্টেম থিম অটো-ডিটেক্ট, নিজের পছন্দ সেভ থাকে
- **অফলাইন সাপোর্ট** — Service Worker দিয়ে ইন্টারনেট ছাড়াও কাজ করে
- **রেসিপি সার্চ ও প্রিয়** — সার্চ, বয়স ফিল্টার, ♥ প্রিয় মার্ক

## টেকনোলজি

- HTML5, CSS3 (Custom Properties, Grid, Responsive)
- Vanilla JavaScript (ES5-compatible)
- Canvas API (ইমেজ কার্ড)
- Notification API + Service Worker (PWA)
- localStorage (ডেটা সংরক্ষণ)

## GitHub Pages-এ হোস্ট করা

1. এই রিপোজিটরিতে সব ফাইল আপলোড করুন
2. **Settings → Pages** → Source: `main` branch, `/ (root)`
3. কিছুক্ষণ পরে সাইট লাইভ হবে
